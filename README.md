A sleek and responsive **Stopwatch web application** built with HTML, CSS, and JavaScript. Track hours, minutes, seconds, and milliseconds with smooth animations and gradient effects. Perfect for timing tasks, workouts, or everyday activities.

---

## 🚀 Features

- Start, Stop, and Reset functionality  
- Displays **hours, minutes, seconds, milliseconds**  
- Smooth real-time updating using `setInterval`  
- Stylish, modern design with gradients and animations  
- Fully responsive and works on any screen size  
- Interactive buttons with hover and click effects
